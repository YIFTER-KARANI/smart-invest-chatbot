# SmartInvest - AI Investment Chatbot

An intelligent chatbot designed to help young Kenyans (ages 18-30) learn about investing in Money Market Funds and NSE stocks.

🌐 **Live Demo:** [https://yifter-karani.github.io/smart-invest-chatbot/](https://yifter-karani.github.io/smart-invest-chatbot/)

---

## 📋 About The Project

SmartInvest is an educational chatbot that provides personalized investment guidance for young Kenyan adults. It combines interactive chat functionality with comprehensive investment knowledge to make financial education accessible and engaging.

**Target Users:** Young Kenyan adults (18-30 years) interested in starting their investment journey

**Focus Areas:**
- Money Market Funds (MMFs) - Cytonn, Sanlam, NCBA, etc.
- Nairobi Securities Exchange (NSE) stocks
- Investment basics and risk management
- Getting started with small amounts (from KES 100)

## 💻 Installation & Local Development

1. **Clone the repository**
```bash
   git clone https://github.com/yifter-karani/smart-invest-chatbot.git
```

2. **Navigate to project folder**
```bash
   cd smart-invest-chatbot
```

3. **Open in browser**
   - Simply open `index.html` in your browser
   - No build process or dependencies needed!
